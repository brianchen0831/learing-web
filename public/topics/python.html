🐍 Python Basics

Variables & printing

name = "Ada"
age = 12
print("Hello,", name)
print("Next year you will be", age + 1)

Loops & conditions

for i in range(1, 6):
    if i % 2 == 0:
        print(i, "is even")
    else:
        print(i, "is odd")

Python uses indentation (spaces) to group code instead of braces.

Functions & lists

def square(x):
    return x * x

nums = [1, 2, 3]
print([square(n) for n in nums])  # [1, 4, 9]

Run it yourself

Save code as hello.py and run python hello.py in a terminal.

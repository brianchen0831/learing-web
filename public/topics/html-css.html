🌐 HTML & CSS Basics

HTML: the structure

HTML uses tags to describe the parts of a page: headings, paragraphs, links and images.

<h1>My Page</h1>
<p>Hello, <a href="https://example.com">world</a>!</p>

CSS: the style

CSS selects elements and changes how they look.

p { color: teal; font-size: 20px; }

I am styled with CSS!
